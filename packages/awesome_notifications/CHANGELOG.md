## 1.0.0-dev.1

* Android: the shared engine (`me.carda.android_awn_core`) ships inside the package, so the plugin builds from pub.dev.
* iOS / macOS: the shared engine (`IosAwnCore`) ships as real files in the package, so it builds with Flutter 3.50.1's copied plugins.

* The README images (banner and screenshots) load from a fixed commit, so they show on pub.dev.
